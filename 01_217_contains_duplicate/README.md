1)	Нужно проверить, повторяются ли элементы в последовательности. Самым наивным и очеведным является реализация через vector, поиск в котором бы в худшем случае совершался за O(N), N - количество элементов. Используя unordered_map мы упрощаем поиск, делая его в среднем O(1), итого сложность O(N). В frequency ключ- само число, а значение это частота, если частота > 0, выходим из цикла и возвращаем true как нас и просили.
