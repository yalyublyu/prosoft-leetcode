Нас просят проверить, является ли строка s анаграммой строки t, то есть перестановкой символов. Для решения я использовала, как и в прошлой задаче unordered_map. Если сделать символ строки ключом, а значение частотой этого символа в строке, то для анаграммы к концу цикла прохода по строке получится, что все значения равны 0. Итак, сначала мы проверяем одной ли длины строки t и s. После заводим unordered_map <char int> same_count, ключ – буква строки, значение –частота появления. Проходимся циклом от 0 до длины строки s, same_count[s[i]]++ ; same_count[t[i]]--; добавляем к счетчику частоты s[i] символа, но сразу же вычитаем для t[i] символа. Таким образом, если символы и их частота в конце равны нулю, то строки анаграммы.
