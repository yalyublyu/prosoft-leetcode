Нужно найти подмассив с наибольшей суммой. Очевидный перебор всех подмассивов имел бы квадратичную сложность. Я использовала алгоритм Кадане.
Идея заключается в том, что мы проходим по массиву и на каждом шаге решаем, выгодно ли нам продолжать накопление текущей суммы prev_sum + num или будет выгодно начать новый подмассив с текущего числа num. Переменная prev_sum = max(prev_sum + num, num) хранит максимальную сумму, заканчивающуюся в текущей позиции, а result фиксирует максимальное значение prev_sum, встреченное за весь проход, которое и является ответом. Такой алгоритм позволяет нам со сложностью O(N) найти подмассив с макс. суммой, путем отбрасывания заранее невыгодных подмассивов.
