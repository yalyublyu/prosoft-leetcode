Нужно вернуть k самых часто встречающихся элементов. Сначала мы проходим по массиву и считаем частоту каждого числа с помощью unordered_map<int, int> counts, где ключ - число, а значение - его частота (сложность O(N)).
Далее нам нужно отсортировать элементы по частоте, а частота может быть одинаковой у некоторых чисел и сортировка недоступна для unordered_map, я переложила пары в multimap<int, int> frequency, изменив порядок на {частота, число}, чтобы выполнять поиск по ключу-частоте. multimap автоматически сортирует элементы по ключу по возрастанию. После этого мы с помощью реверсивного итератора rbegin() проходим с конца контейнера, где лежат самые большие частоты и забираем первые k элементов. Итоговая сложность O(N log N) по времени и O(N) по памяти.
